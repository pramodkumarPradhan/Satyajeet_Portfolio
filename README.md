# Satyajeet Behera — Premium Portfolio
Built from the supplied CV. Includes responsive design, dark/light mode, animations, mobile navigation, resume download, experience, projects, skills, education and contact sections.

Completed projects are only those represented in the CV. "Build Next" projects are recommendations, not claimed completed work.

Design research used public GitHub portfolio patterns for responsive layouts, theme switching, motion and project showcases:
- https://github.com/waqas120/portfolio
- https://github.com/tichita7/tichita-dev
- https://github.com/diip3sh/portfolio
- https://github.com/ajay-dhangar/alex-portfolio

Open `index.html` directly, or deploy the folder to GitHub Pages, Netlify or Vercel.
